### **Уровень 0: Визуальный обзор (15-40 минут)**

### **Уровень 1: Онбординг (0-30 минут)**
Для новых разработчиков в первый день работы с проектом.

### **Уровень 3: Практическая разработка (90+ минут)**
Перед созданием первого Pull Request.

- [**06. Development Workflow**](06-development-workflow.md) - Процесс разработки

## 📖 Рекомендуемый порядок изучения

### Визуальное введение (опционально):
0. **Visual Overview** → посмотреть все диаграммы (для visual learners)

### Первый день:
1. **Getting Started** → запустить проект
2. **Repository Tour** → понять структуру
3. **Troubleshooting** → держать открытым на случай проблем

### Первая неделя:
4. **Architecture Overview** → понять как работает система
5. **Data Model** → разобраться с данными
6. **Development Workflow** → научиться работать с кодом

### Перед первым PR:
7. **Testing Strategy** → написать тесты
8. **Code Review Process** → подготовить PR к ревью
