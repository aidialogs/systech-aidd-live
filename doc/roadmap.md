## Запланированные спринты

### Sprint S2: Сохранение Telegram username (📋 Planned)

**Цель:** Автоматически сохранять и обновлять Telegram username пользователей в базе данных при каждом их обращении к боту.

**Основные задачи:**
- Добавить поле `username` (nullable String) в модель `User`
- Создать миграцию Alembic для добавления колонки `username` в таблицу `users`
- Расширить метод `ensure_user()` в `MessageRepository` для приема и сохранения/обновления username
- Обновить обработчики сообщений (`message_handler.py`) для передачи `message.from_user.username` в repository
- Добавить индекс для поля `username` для быстрого поиска (опционально)
- Обновить все тесты для корректной работы с новым полем
- Обновить документацию (README, ER-диаграмма схемы БД)

**Технические детали:**
- Поле `username` должно быть nullable (не у всех пользователей есть username в Telegram)
- При каждом обращении пользователя нужно обновлять username, если он изменился
- Сохранять значение `None` если у пользователя нет username

**Ожидаемый результат:**
- В таблице `users` хранится актуальный Telegram username каждого пользователя
- Username автоматически обновляется при изменении
- Покрытие тестами остается на уровне ~90%+
