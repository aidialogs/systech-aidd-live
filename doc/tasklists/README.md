# Tasklists - Планы разработки по спринтам

Эта директория содержит детальные планы разработки (tasklists) для каждого спринта проекта.

## 📁 Структура файлов

Тасклисты именуются по следующему шаблону:

```
tasklist-<код_спринта>.md         # Основной тасклист спринта
tasklist_<название>-<код_спринта>.md  # Дополнительный тасклист с конкретным фокусом
```

## 📊 Формат тасклистов

Каждый тасклист содержит:

1. **Заголовок** - название и номер спринта
2. **Отчет по прогрессу** - таблица со статусом итераций
3. **Легенда статусов** - расшифровка иконок статусов
4. **Итерации разработки** - детальный план каждой итерации:
   - Цель итерации
   - Обоснование (если применимо)
   - Файлы для создания/изменения
   - Чекбоксы для отслеживания прогресса
   - Архитектура
   - Функционал
   - Тестовые сценарии
   - Критерии завершения

## 💡 Как использовать

1. **Перед началом спринта**: Прочитайте соответствующий тасклист полностью
2. **Во время разработки**: Отмечайте выполненные чекбоксы
3. **После итерации**: Обновляйте таблицу прогресса с датами
4. **После спринта**: Обновляйте статус спринта в роадмапе
