# Идея: LLM-ассистент в виде Telegram-бота

## Описание проекта

Разработка LLM-ассистента, реализованного в виде Telegram-бота. Базовый ИИ-ассистент превращается в полноценный ИИ-продукт с конкретной ролью **AICodingExpert** - эксперта по программированию и разработке.

## Основные функции

- **Ведение диалога с пользователем** - бот должен поддерживать естественную беседу
- **Ответы на вопросы в заданной роли** - ассистент работает в роли AICodingExpert, четко обозначенной через системный промпт
- **Команда `/role`** - отображение текущей роли и специализации ассистента
- **Конфигурируемая роль через системный промпт** - роль и поведение ассистента задаются через системный промпт, хранящийся в отдельном файле

## Роль: AICodingExpert

Ассистент выполняет четко обозначенную функцию эксперта по программированию:
- Помощь в написании кода
- Код-ревью и оптимизация
- Объяснение концепций программирования
- Решение технических проблем
- Рекомендации по архитектуре и best practices

## Технические требования

- Платформа: Telegram Bot API
- Интеграция с LLM (Large Language Model)
- Поддержка контекста беседы
- Хранение системного промпта в конфигурационном файле
- Команды бота: `/role` для отображения роли
