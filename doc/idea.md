# Идея: LLM-ассистент в виде Telegram-бота

## Описание проекта

Разработка LLM-ассистента, реализованного в виде Telegram-бота.

## Основные функции

- **Ведение диалога с пользователем** - бот должен поддерживать естественную беседу
- **Ответы на вопросы в заданной роли** - ассистент работает в определенной роли, заданной по умолчанию

## Технические требования

- Платформа: Telegram Bot API
- Интеграция с LLM (Large Language Model)
- Поддержка контекста беседы
