# DevOps Sprint Plans

Эта директория содержит детальные планы реализации для каждого DevOps спринта.

## Structure

Каждый план создается в режиме **Plan Mode** перед началом спринта и содержит:

- Детальную разбивку задач
- Технические решения и подходы
- Чеклисты для проверки готовности
- Ссылки на созданные файлы и PR

## Plans

- `sprint-D0-plan.md` - Basic Docker Setup
- `sprint-D1-plan.md` - Build & Publish
- `sprint-D2-plan.md` - Развертывание на сервер
- `sprint-D3-plan.md` - Auto Deploy

## Workflow

1. **Plan Mode**: Создание детального плана спринта
2. **Implementation**: Реализация по плану
3. **Review**: Проверка соответствия критериям готовности
4. **Link Update**: Обновление ссылки в roadmap после завершения
