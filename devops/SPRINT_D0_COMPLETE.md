## Выполненные задачи

### ✅ 1. Созданы Dockerfiles для всех сервисов

**devops/Dockerfile.bot**
- Базовый образ: Python 3.11-slim
- Установка uv для управления зависимостями
- Копирование исходного кода (src/, alembic/, prompts/)
- Автоматическое применение миграций при запуске
- CMD: `uv run alembic upgrade head && uv run python -m src.main`

**devops/Dockerfile.api**
- Базовый образ: Python 3.11-slim
- Установка uv для управления зависимостями
- Копирование исходного кода (src/, alembic/)
- Expose порт 8000
- CMD: `uv run uvicorn src.api.main:app --host 0.0.0.0 --port 8000`

**devops/Dockerfile.frontend**
- Базовый образ: Node 20-slim
- Установка pnpm
- Копирование package.json и зависимостей
- Expose порт 3000
- CMD: `pnpm dev`

### ✅ 2. Созданы .dockerignore файлы

**.dockerignore** (для Python сервисов в корне проекта)
- Исключает cache файлы, тесты, документацию
- Оптимизирует размер build context
- Ускоряет сборку образов

**frontend/.dockerignore** (для Frontend)
- Исключает node_modules, .next/, build артефакты
- Оптимизирует размер build context

### ✅ 3. Создан docker-compose.yml

**devops/docker-compose.yml**

4 сервиса с правильными зависимостями:

1. **postgres** - PostgreSQL 16-alpine
   - Healthcheck для корректного запуска зависимых сервисов
   - Volume для персистентного хранения данных
   - Порт 5432

2. **bot** - Telegram Bot
   - Зависит от postgres (с condition: service_healthy)
   - Применяет миграции автоматически
   - Использует .env файл для конфигурации
   - Volume для логов

3. **api** - FastAPI сервер
   - Зависит от postgres (с condition: service_healthy)
   - Expose порт 8000
   - Использует .env файл для конфигурации
   - Volume для логов

4. **frontend** - Next.js
   - Зависит от api
   - Expose порт 3000
   - NEXT_PUBLIC_API_URL настроен на localhost:8000

## Как использовать

### Быстрый старт

```bash
# 1. Создайте .env файл
cp devops/env.example .env
nano .env  # Заполните BOT_TOKEN, LLM_API_KEY и др.

# 2. Запустите все сервисы
cd devops
docker compose up
```

### Проверка работоспособности

- Frontend: http://localhost:3000
- API: http://localhost:8000/docs
- Health: http://localhost:8000/health
- Bot: работает в Telegram

### Полезные команды

```bash
cd devops

make help          # Справка по всем командам
make build         # Собрать образы
make up            # Запустить сервисы
make down          # Остановить сервисы
make logs          # Показать логи
make test          # Запустить тесты
```
