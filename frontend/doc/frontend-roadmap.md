## Спринт S1: Требования к дашборду и Mock API для получения статистики

**Статус**: ✅ Completed  
**План**: [s1-mock-api-plan.md](plans/s1-mock-api-plan.md)

### Цели
- Определить функциональные требования к дашборду статистики
- Создать контракт API для frontend
- Реализовать Mock API с возможностью замены на реальную реализацию

### Состав работ
- Формирование функциональных требований к дашборду для статистики по диалогам на основе существующих возможностей системы
- Проектирование контракта API для frontend (единый метод для получения статистики в соответствии с требованиями UI)
- Проектирование интерфейса `StatCollector` с возможностью двух реализаций: Mock и Real
- Реализация Mock-версии сборщика статистики
- Автоматическая генерация документации API
- Создание entrypoint для запуска API-сервера
- Создание команд для запуска API и тестирования получения статистики

### Результаты
- ✅ FastAPI приложение с endpoint `GET /api/v1/statistics`
- ✅ Поддержка параметра `period` (day|week|month|all)
- ✅ Protocol pattern для Mock/Real реализаций
- ✅ MockStatCollector с генерацией реалистичных данных
- ✅ Автоматическая документация (Swagger UI, ReDoc)
- ✅ Makefile команды: `api-run`, `api-test`, `api-docs`
- ✅ 10 тестов с 100% покрытием API модулей
- ✅ Примеры использования API ([api-examples.md](../../doc/api-examples.md))

## Спринт S4: Реализация ИИ-чата

**Статус**: ✅ Completed  
**План**: [s4-chat-plan.md](plans/s4-chat-plan.md)

### Цели
- Создать интерфейс веб-чата для администратора
- Реализовать backend API для чата
- Интегрировать с LLM для аналитики диалогов
- Перевести дашборд с Mock API на реальную БД

### Референсы
- [expandable-chat-prompt.md](references/expandable-chat-prompt.md) - Референс компонента чата от 21st.dev

### Состав работ
- Реализация UI чата на основе референсного дизайна
- Разработка API для чата (аналог функционала бота)
- Реализация функционала для администратора: ответы на вопросы по статистике диалогов через цепочку (вопрос → промпт для text2sql → выполнение SQL → результат в LLM → ответ пользователю)
- Интеграция чата с backend API
- Тестирование и отладка функционала чата

### Результаты
- ✅ RealStatCollector с SQL запросами к БД для статистики
- ✅ ChatHandler с поддержкой normal и admin режимов
- ✅ Text2SQL pipeline для admin режима (вопрос → SQL → выполнение → LLM → ответ)
- ✅ Chat API endpoints: `/api/v1/chat/message`, `/api/v1/chat/history`
- ✅ 9 UI компонентов для чата (avatar, chat-bubble, expandable-chat, и др.)
- ✅ ChatInterface компонент с загрузкой истории и отправкой сообщений
- ✅ ModeToggle для переключения Normal/Admin режимов
- ✅ FloatingChatButton на dashboard и главной странице
- ✅ Полноэкранная страница `/chat`
- ✅ Дашборд работает с реальной БД (RealStatCollector)
- ✅ Makefile команды для тестирования chat API

## Спринт S5: Переход с MockAPI на реальный API

**Статус**: ✅ Completed (реализовано в S4)

### Цели
- Реализовать реальный сборщик статистики
- Переключить систему с Mock на реальную реализацию
- Обеспечить полную интеграцию с базой данных

### Состав работ
- Реализация реального сборщика статистики (`StatCollector`) с использованием базы данных
- Интеграция с существующей базой данных проекта
- Переключение конфигурации с Mock на Real реализацию
- Тестирование работы с реальными данными
- Верификация корректности статистики и производительности

### Результаты
- ✅ RealStatCollector реализован в Sprint S4
- ✅ Конфигурация через `STAT_COLLECTOR_MODE=real`
- ✅ Все SQL запросы работают с реальной БД
- ✅ Dashboard показывает реальную статистику
- ✅ Mock и Real режимы переключаются через environment variable
