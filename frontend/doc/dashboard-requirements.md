# Функциональные требования к дашборду статистики

## Обзор

Дашборд предназначен для отображения статистики по диалогам с Telegram-ботом. Дашборд должен показывать ключевые метрики и динамику активности пользователей за выбранный период.

**Референс:** [Shadcn Dashboard](https://ui.shadcn.com/blocks#dashboard-01)

---

## Метрики (4 карточки)

### 1. Количество пользователей
- **Название:** "Всего пользователей" / "Total Users"
- **Значение:** Общее количество зарегистрированных пользователей (из таблицы `users`)
- **Тренд:** Процент изменения за последние 30 дней (относительно предыдущих 30 дней)
- **Формат:** Число с разделителями тысяч (например: 1,250)

### 2. Количество диалогов
- **Название:** "Активных диалогов" / "Active Chats"
- **Значение:** Количество уникальных `chat_id` с сообщениями
- **Тренд:** Процент изменения за последние 30 дней
- **Формат:** Число с разделителями тысяч (например: 1,234)

### 3. Количество сообщений
- **Название:** "Всего сообщений" / "Total Messages"
- **Значение:** Общее количество сообщений (из таблицы `messages`)
- **Тренд:** Процент изменения за последние 30 дней
- **Формат:** Число с разделителями тысяч (например: 45,678)

### 4. Средняя длина сообщения
- **Название:** "Средняя длина" / "Avg Message Length"
- **Значение:** Среднее значение поля `content_length` по всем сообщениям
- **Тренд:** Процент изменения за последние 30 дней
- **Формат:** Целое число символов (например: 142)

---

## График Timeline

### Назначение
Отображение динамики количества сообщений по дням за выбранный период.

### Данные
- **Ось X:** Даты (формат: "MMM DD", например "Oct 10")
- **Ось Y:** Количество сообщений
- **Точки данных:** Количество сообщений за каждый день

### Фильтры периодов
1. **Last 7 days** - последние 7 дней (7 точек на графике)
2. **Last 30 days** - последние 30 дней (30 точек на графике)

### Визуализация
- Тип графика: Area chart (график с заливкой области)
- Линия графика с плавными переходами
- Заливка под линией с градиентом (полупрозрачная)
- Темная цветовая схема

---

## Требования к отображению трендов

### Визуальные индикаторы
- **Положительный тренд:** 
  - Иконка: ↗ (trending up)
  - Цвет: Зеленый
  - Формат: "+12.5%"
  
- **Отрицательный тренд:**
  - Иконка: ↘ (trending down)
  - Цвет: Красный
  - Формат: "-5.2%"

- **Нейтральный тренд (0%):**
  - Иконка: → (стрелка вправо)
  - Цвет: Серый
  - Формат: "0.0%"

### Расположение
- Тренд отображается в правом верхнем углу карточки метрики
- Размер иконки: малый
- Процент отображается рядом с иконкой

## API Requirements

### Endpoint
```
GET /api/stats?period={7d|30d}
```

### Response Structure
```json
{
  "metrics": {
    "total_users": {
      "value": 1250,
      "trend": 12.5
    },
    "total_chats": {
      "value": 1234,
      "trend": -5.2
    },
    "total_messages": {
      "value": 45678,
      "trend": 8.3
    },
    "avg_message_length": {
      "value": 142,
      "trend": 3.1
    }
  },
  "timeline": [
    {
      "date": "2025-10-10",
      "messages": 1523
    },
    {
      "date": "2025-10-11",
      "messages": 1687
    }
  ]
}
```

### Параметры
- `period` - период для фильтрации (enum: "7d" | "30d")
  - `7d` - последние 7 дней
  - `30d` - последние 30 дней

### Поля данных
- `metrics` - объект с 4 метриками
  - каждая метрика содержит `value` (число) и `trend` (процент изменения)
- `timeline` - массив точек данных для графика
  - `date` - дата в формате ISO (YYYY-MM-DD)
  - `messages` - количество сообщений за этот день
